## 一句话认识 dsh

**dsh 是一个"一切皆插件"的 agent 运行时**：模型适配器、工具注册表、会话日志、甚至 agent 循环本身都是 Cordis 插件，全部可以从配置层替换。`dsh web` 这个产品只是官方用插件拼出的一种默认组合。

## 推荐学习路线

**第一层：建立世界观（半天）**
1. 读 01 → 02，跑 `dsh --profile web --dump-config` 亲眼看合成树
2. 记住三条铁律：一切注册皆 effect / 模型可见 ⟺ 已落日志 / 新行为挂扩展点不改循环

**第二层：吃透心脏（一到两天）**
3. 读 03 → 04，对照源码 `packages/core/agent-loop/src/agent.ts`（~500 行，值得逐行读）
4. 读 05，扫一遍 `docs/capability-seams.md` 生成图，理解"接缝三角色"

**第三层：动手（一天）**
5. 按 06 的骨架写一个玩具工具插件，用 `--patch` 挂上跑通
6. 想做 UI/协议对接再读 07

**源码精读推荐顺序**（每个都短小精悍）：
- `vendor/cordis/src/events.ts` 的 `waterfall()` —— 20 行看懂全部策略机制
- `packages/core/session/src/types.ts` —— 事件词汇表即系统契约
- `packages/core/agent-loop/src/agent.ts` —— 心脏
- `packages/shell/`（shell 接缝三角色）—— 官方钦定的 seam 模板
- `packages/bundle/base/cordis.patch.yml` —— 产品 = 一列配置行

## 我认为最值得借鉴的五个设计决策

1. **日志优先（log-first）**：模型上下文、UI、恢复、遥测全部从一条 append-only 事件流派生。压缩用 surface `replace` 而非删除——历史永远完整。
2. **策略与能力解耦**：工具本体零策略；沙箱/权限/hook/审计横跨全部工具族。fail-closed 审批（无应答者=拒绝）。
3. **纪元驱动的生命周期**：依赖的提供者换人=纪元变化=消费者自动重载，HMR 因此"暴力但正确"。
4. **配置即产品**：web/headless 只是补丁层堆叠差异；用户任何一层都能替换任意行。浏览器前端同样由宿主配置组合，前端壳零决策。
5. **防御性版本策略**：未识别且未标 `ignorable` 的事件 → 拒绝重建会话。宁可过度拒绝，不可静默读坏。

## ⚠️ 本轮（0.1.2 → 0.2.0）推翻的旧结论

跨了一个大版本，有多条写在前几轮文档里的事实已经不成立。各篇已原地更正，这里集中列出便于核对：

| 旧结论 | 现状 | 更正位置 |
|---|---|---|
| 任一插件加载失败 → 整棵插件树 abort → 服务起不来 | **只有 7 个必需条目能中止启动**，其余失败只打一行 warning、服务照常跑 | [15](15-插件生命周期与可观测性.md)、`ops/03` |
| `SESSION_FORMAT_VERSION = 0`，无兼容承诺 | **= 4**，四条迁移边 + 完整治理体系 | [03](03-Agent循环与会话日志.md)、[12](12-会话格式版本化与持久化治理.md) |
| 持久化事件名 `tool/code-dispatch*` 刻意保持不变 | **已改名 `tool/ptc-dispatch*`**（v2→v3），v4 硬拒旧名 | [04](04-工具系统与执行管线.md) |
| 存储行是打包 chunk rows（`seq0`/`time0`/`dt`/`texts`） | 顶层打包行已不存在；字段名保留但搬进 `assistant/message.data.stream[]` | [03](03-Agent循环与会话日志.md) |
| `$DSH_HOME/settings.yaml` 是配置位置且热重载 | **文件已删除**，一次性导入 profile 后改名 `.imported`；配置改到 profile 的 `cordis.patch.yml` | [15](15-插件生命周期与可观测性.md)、`ops/06` |
| PTC 运行时在 `packages/code-runtime/*`，worker thread 隔离 | 换址 `packages/ptc-runtime/*`，**换成 OS 沙箱约束的独立进程** | [04](04-工具系统与执行管线.md) |
| 远程执行由 E2B 提供 | E2B 整组删除，换成 SSH provider family（**但未在任何出厂 profile 挂载**） | [14](14-远程执行与账号体系.md) |
| 有 jsonl 和 sqlite 两种会话持久化 | **只剩 JSONL**，sqlite 包已删且**无自动迁移路径** | [03](03-Agent循环与会话日志.md) |
| Agent Teams 需要 Host + Web 两个 bundle | 合并为单 bundle；**旧 profile 选过被删的包会启动失败，无自动迁移** | [08](08-AgentTeams多代理协作.md) |
| `llm-deepseek` 是 DeepSeek provider 插件 | 降级为**共享协议库**，provider 注册搬到 `llm-deepseek-api-key` | [14](14-远程执行与账号体系.md) |

**仍然成立的关键结论**（本轮验证过）：Cordis 内核五个核心文件**字节级未变**；
`.credentials.yaml` 的 `refs:` / `records:` 两段式**零语义变更**；
客户端 `conversation.view` 插槽**仍然有效**。
